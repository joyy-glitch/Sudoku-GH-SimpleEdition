How to play

The goal

Fill every empty square with an Adinkra symbol. Each row, each column and each box (the areas inside the thick lines) must have every symbol exactly once.

Placing a symbol

Tap a square on the board first, then tap a symbol. The square's row, column and box light up so you can see what's already there.

Tap any symbol on the board to read what it means in the purple card.

When a symbol has been placed everywhere it belongs, its button fades out.

Tools

Undo takes back your last move. It doesn't take back a mistake.

Erase clears the selected square.

Numbers shows a number in the corner of each symbol, for a classic sudoku feel.

Hint fills the selected square with the right symbol. You get one per puzzle.

Mistakes

A wrong symbol turns red and counts as a mistake.

Level 1 (4×4): 3 mistakes · Level 2 (6×6): 4 mistakes · Level 3 (9×9): 5 mistakes

Run out and the game ends. Start a new puzzle to try again.

Scoring

+10 for each square you fill correctly

−5 for each mistake

+20 bonus for every mistake you had left when you finish

Levels and symbols

Finish a level to unlock the next grid and its new symbols. Visit Symbols to learn their meanings, then test yourself with the Quiz.

Easy, Medium and Hard change how many squares start empty.

Use the moon button to switch between dark and light mode.
